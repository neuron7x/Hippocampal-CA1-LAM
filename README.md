# Hippocampal-CA1-LAM
CA1-Laminar: Neuromath framework for 4-layer CA1 hippocampus (Pachicano et al., Nat Comm 2025). ZINB sublayers (58k cells), 2-compartment biophysics, Ca²⁺ plasticity (Graupner PNAS 2012), theta/SWR modes. Full code, DOI params, golden tests (seed=42, tol&lt;1e-10), ρ(W)&lt;1.0 stability. LLM memory module (HippoRAG). Reproducible in silico neuroscience.
